# Как править содержимое

Тексты объяснений лежат прямо в `index.html` — правите то, что видите.
Слова и задания лежат в `data.js`: задания строятся из базы автоматически,
вручную их писать не нужно.

Самый удобный способ: открыть нужный файл на github.com, нажать карандаш,
поправить, сохранить. Netlify пересоберёт сайт за полминуты.

**После любой правки `data.js` запустите `node test.js`.** Скрипт проверит
формы, ссылки сцен и сборку заданий и назовёт строку с ошибкой.

## Добавить существительное

Одна строка в списке `NOUNS`:

```js
n('lentynėlė', 'полочка', 'f', 'ė', 'furniture');
//  имя         перевод    род  модель  профиль сцены
```

Модели склонения: `as`, `ias`, `is`, `ys`, `us`, `ius`, `a`, `ė`,
`is3` (третье склонение: moteris, dantis, vinis). Формы считаются сами.

Слова с особой основой или без одного из чисел задаются формами целиком:

```js
x('šuo', 'собака', 'm', ['šuo', 'šunys'], ['šunį', 'šunis'], 'pet',
  'Особая основа šun-. Мужское множественное винительного: šunis.');
//   имя  перевод  род   kas? ед./мн.      ką? ед./мн.       профиль  примечание
```

Пустая строка в формах означает, что формы нет в изучаемом значении
(`durys` без единственного, `vanduo` без множественного). Не подставляйте
туда форму по догадке: тренажёр не предложит недоступное число.

## Добавить прилагательное

```js
a('šviežias', 'свежий');
```

Четыре формы для обоих падежей считаются по окончанию, порядок везде один:
jis, ji, jie, jos. Исключение задаётся третьим аргументом — точной моделью.

## Добавить глагол

```js
v('vėdinti', 'проветривать', 'vėdina', 'vėdino');
//  инфинитив  перевод        3-е л. наст.  3-е л. прош.
```

Остальные формы строятся сами. Особые случаи — пятым аргументом:
`{ fut3: '…', imp: '…', note: 'что важно сказать ученику' }`.

## Связать предмет с описаниями и действиями

Сцены опубликованной версии заданы явно в `SCENES_V4` — это точные связи
«предмет → восемь описаний → действия». Новый предмет добавляется туда же:

```js
lentynėlė: { adj: ['naujas', 'senas', 'didelis', 'mažas', 'gražus', 'švarus', 'nešvarus', 'sunkus'],
  act: ['matyti', 'pirkti', 'parduoti', 'valyti', 'pakeisti', 'apžiūrėti', 'fotografuoti', 'pasirinkti'] },
```

Предметы без явной сцены получают наборы из тематического профиля
(`PROFILES`). Профиль — обучающая опора, а не проверенная сочетаемость:
каждый новый набор стоит перечитать глазами.

Все действия должны быть переходными: объект отвечает на ką?
Глагол с другим управлением (`laukti draugo`, `padėti draugui`) в сцену
не ставим.

## Добавить перевод

Список `TRANSLATIONS`, в конец:

```js
['Я мою чистое окно.', ['Aš plaunu švarų langą', 'Plaunu švarų langą'],
 'langas — jis; ką? švarų langą.', 'plauti'],
// русское предложение, допустимые литовские варианты, объяснение, глагол
```

Вариантов может быть сколько угодно — чем их больше, тем реже верный ответ
ученика останется неподтверждённым. Вставлять новые переводы **только в
конец**: они нумеруются по порядку, и вставка в середину сдвинет ID.

## Что нельзя менять без последствий

ID заданий составлены из ID слов: `agreement:langas:švarus:0:acc`,
`action:vonia:plauti:baltas:0`, `forms:gražus:nom`. Добавление слов,
описаний и действий старые ID не трогает. Переименование или удаление
слова, перестановка описаний внутри сцены обнуляют сохранённые ответы
учеников по этим заданиям.

## Поменять цвета и шрифты

Всё в начале `styles.css`, в блоке `:root`; ниже те же переменные для
тёмной темы — их нужно менять парой. Шрифты подключены строкой
`fonts.googleapis.com` в `<head>` каждой страницы и заданы переменными
`--dd-head` / `--dd-sans`. Шрифт должен поддерживать литовскую диакритику
(ą č ę ė į š ų ū ž) и кириллицу.
