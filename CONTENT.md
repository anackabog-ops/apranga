# Как править содержимое

Весь текст лежит прямо в HTML-страницах. Никакого шаблонизатора — правите то,
что видите. Самый удобный способ: открыть нужный файл на github.com,
нажать карандаш, поправить, сохранить. Netlify пересоберёт сайт за полминуты.

## Добавить слово в таблицу

Найдите нужную таблицу в `zodynas.html` и скопируйте строку целиком:

```html
<tr>
  <td class="w">striukė</td>
  <td><span class="tag t-ji">ji</span></td>
  <td class="n">striukės</td>
  <td class="g">куртка</td>
</tr>
```

Классы: `w` — литовское слово, `n` — множественное число, `g` — перевод.
Род: `t-jis` мужской, `t-ji` женский, `t-pl` только множественное.

Поиск подхватит новую строку сам. Ударения ему не мешают: перед сравнением
он снимает всю диакритику, поэтому запрос «paltas» найдёт и `pal̃tas`.

## Добавить раздел на существующую страницу

Скопируйте блок `<section id="…"> … </section>`, поменяйте `id`
и добавьте ссылку в боковое меню (`<nav class="rail">`) и в мобильное
содержание (`<details class="toc-mobile">`) на той же странице.

Нумерация в `<span class="sec-num">§ N · Подзаголовок</span>` — сквозная
внутри страницы, её тоже поправьте.

## Добавить новую тему целиком

1. Скопируйте файл любого раздела, например `jos.html`, и переименуйте —
   имя файла станет адресом страницы.
2. Внутри поменяйте `<title>`, `<meta name="description">`,
   `<link rel="canonical">`, `<meta property="og:url">`, заголовок,
   вводный абзац и содержимое.
3. Добавьте страницу в верхнее меню — оно повторяется в каждом файле,
   в блоке `<nav class="topnav">`, — и в подвал.
4. Добавьте карточку на главной, в нужный блок «Тема».
5. Допишите адрес в `sitemap.xml`.
6. Проверьте, что в `<head>` остались `<meta name="author">`,
   `<meta name="copyright">`, `<link rel="license" href="teises.html">`
   и блок `application/ld+json` — в нём поправьте `name`, `url`
   и `description` под новую страницу. Остальные поля (автор,
   правообладатель, год, лицензия) везде одинаковые.

Все ссылки между страницами относительные: `href="kursas.html"`, без слеша
в начале. Слеш в начале сломает открытие с диска.

## Упражнения

### С выбором варианта

```html
<ol class="ex-choice">
  <li>
    <span class="ex-q"><b>Jõs mama dirba.</b></span>
    <span class="ex-opts">
      <button class="opt" type="button" data-ok="1">её</button>
      <button class="opt" type="button">они</button>
    </span>
    <span class="ex-why">Объяснение, которое покажется после ответа.</span>
  </li>
</ol>
<p class="score">Отвечено: 0 / 1</p>
```

Правильный вариант помечается атрибутом `data-ok="1"`. Вариантов может быть
сколько угодно. Счётчик под списком обновляется сам — важно только, чтобы
`<p class="score">` лежал в том же разделе.

### С раскрытием ответа

```html
<ol class="ex-reveal">
  <li>
    <span class="ex-q">Её мама работает в магазине.</span>
    <button class="reveal-btn" type="button">Ответ</button>
    <span class="ex-a">Jõs mama dirba parduotuvėje.</span>
  </li>
</ol>
```

### Тренажёр на странице /treniruokle/

Он собирается скриптом. В `app.js` найдите массив `Q` и добавьте объект:

```js
{ s:['Начало предложения ',' конец.'],
  o:['вариант1','вариант2','вариант3'],
  a:0,                       // индекс правильного, считая с нуля
  w:'Объяснение, которое покажется после ответа.' }
```

### Тренажёр на странице /linksniai/

Он тоже собирается скриптом, но данные лежат отдельно — в `linksniai.js`.
Там пять баз (`NOUNS`, `ADJS`, `VERBS`, `NOT_ACC`, `DERIV`) и массив блоков
`DRILLS`. Чтобы добавить задание, найдите нужный блок и допишите объект:

```js
{ q: 'Matau … <i>(naujas langas)</i>',   // вопрос, можно с разметкой
  hint: 'Действие matau требует ką?',    // подсказка до ответа
  ans: ['naują langą'],                  // что принимать при вводе с клавиатуры
  rule: 'a → ą: naujas langas → naują langą',
  opts: [                                // объяснение нужно у КАЖДОГО варианта
    { t:'naują langą',  ok:1, w:'Оба слова на -as, обе гласные уходят в ą.' },
    { t:'naujas langas', ok:0, w:'Это vardininkas — имя предмета.' } ] }
```

`ans` — массив: перечислите все допустимые написания (например, с местоимением
и без). Проверка сама снимает знаки ударения, лишние пробелы и знаки препинания,
а нехватку литовских букв показывает отдельно — как «почти», а не как «верно».

Задание с переводом целого предложения отличается полем `bd` — разбором по
словам; при его наличии вместо строки ввода появляется многострочное поле:

```js
bd: [ {w:'Matau', e:'«вижу» — 1 л. ед. ч. от matyti.'},
      {w:'langą', e:'langas → langą: a → ą.'} ]
```

Чтобы добавить слово в базу, допишите строку в нужный массив — таблицы в
разделе «Базы слов» и счётчики на вкладках соберутся сами. Формы галининкаса
у прилагательных не хранятся: их считает функция `adjAcc()` по группе и по
форме `jos`, поэтому у нового прилагательного важно правильно указать все
четыре формы (`jis`, `ji`, `jie`, `jos`).

Расписание повторений живёт в `localStorage` под ключом `lk-cases-v1`.
Если поменяете состав заданий так, что старый прогресс станет бессмысленным,
поднимите номер версии в константе `STORE`.

### Тренажёр на странице /schemos/

Здесь формы вообще не хранятся. В `schemos.js` у каждого глагола записаны
только **три главные формы**, а всю парадигму собирает движок:

```js
{inf:'skaityti', pres:'skaito', past:'skaitė', ru:'читать', g:'yti', t:1},
```

`inf` — bendratis, `pres` — третье лицо настоящего, `past` — третье лицо
прошедшего, `ru` — перевод, `g` — ключ группы из массива `GROUPS`,
`t:1` — переходный (зовёт galininkas). Добавили строку — глагол сам
появился в базе, в списке своей группы, в выпадающем списке разбора
и в заданиях практики.

Проверять после добавления нужно ровно одно: верны ли три главные формы.
Всё остальное — настоящее, прошедшее, многократное, будущее, условное,
повелительное и причастия — выводится правилами и ошибиться не может.

У одного глагола, `būti`, настоящее время не выводится ниоткуда, поэтому
у него стоят ручные поля `irrPres` и `irrPart`. Если понадобится добавить
ещё один такой же — делайте по этому образцу.

Группы описаны в массиве `GROUPS`: формула, пояснение, окончания настоящего
и прошедшего, пример и заметка. Новую группу добавляют туда же, а глаголы
привязывают к ней ключом `g`.

Темы для раздела «Мои предложения» — массив `THEMES`, приставки — `PREFIXES`.

## Заменить или добавить иллюстрацию

Картинки лежат в той же папке, что и страницы, — по одному `.webp` на снимок,
имена говорящие (`05-apsiauti-sportbacius.webp`). Чтобы заменить снимок,
загрузите новый файл под тем же именем: в разметке править ничего не нужно.

Чтобы добавить новый, вставьте в нужный раздел блок:

```html
<figure class="fig">
  <img src="имя-файла.webp" alt="Описание для незрячих и поисковиков"
       loading="lazy" width="1000" height="1250">
  <figcaption><b>Lietuviškas pavyzdys.</b> Пояснение по-русски.</figcaption>
</figure>
```

На широком экране подпись встаёт справа от снимка, на телефоне — под ним.
Атрибуты `width` и `height` укажите реальные: они держат место до загрузки,
и страница не дёргается.

Карточки семи корней на странице глаголов — это блок `<div class="vmap">`
с элементами `<div class="vc">`. Седьмая карточка (dė‑) идёт без снимка,
у неё класс `vc text-only`.

## Поменять цвета

Всё в начале `style.css`, в блоке `:root`; ниже — те же переменные
для тёмной темы. Меняйте только значения: поправите `--accent` — обновятся
ссылки, акценты в таблицах, схема тела, кнопки и подсветка активного пункта меню.

У страницы падежей палитра своя — в начале `linksniai.css`. Там же лежат
пять цветов референса (`--peapod`, `--bechamel`, `--going`, `--lava`),
из которых выведены все остальные переменные. Правки в `style.css`
этой страницы не касаются, и наоборот.

## Поменять шрифты

Строка со ссылкой на `fonts.googleapis.com` — в `<head>` каждой страницы,
и переменные `--serif` / `--sans` в начале `style.css`. На странице падежей
их перекрывает `linksniai.css`: заголовки и интерфейс — Manrope,
основной текст — Noto Sans (переменная `--body`).
Проверьте, что шрифт поддерживает и литовскую диакритику (ą č ę ė į š ų ū ž),
и кириллицу, и знаки ударения (á à ã) — иначе часть текста подменится
системным шрифтом.

## Проверить перед публикацией

Просто откройте `index.html` двойным щелчком — ссылки относительные,
сайт работает и с диска. Пройдите по всем десяти страницам: меню, поиск в словаре,
все три тренажёра, переключатель темы, ссылки «предыдущий / следующий раздел» внизу.
На странице падежей проверьте оба режима ответа и обе темы.
