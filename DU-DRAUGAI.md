# «Два друга · Vardininkas и Galininkas» — статус реализации

Автор методики: Божена Анацкая · anacka.lt. Страница: `dudraugai.html`.

Этот файл фиксирует, что из технического задания реализовано на этом сайте,
что реализовано иначе, а чего нет. Не заявлять в описаниях функции из
раздела «Чего нет».

## Как устроено на этом сайте

Сайт — статический (Netlify, плоская папка, без сборки), поэтому тренажёр
сделан как обычная страница с тремя файлами:

| Файл | Роль |
|------|------|
| `dudraugai.html` | вкладки, конструктор, практика, 13 схем, база слов, новые слова, повторы, моё пространство, диалог спряжения |
| `dudraugai-data.js` | существительные, прилагательные, глаголы, профили сцен, словообразование, переводы; функции форм и спряжения |
| `dudraugai.js` | генераторы заданий со стабильными ID, нормализация и проверка, сохранение в браузере, черновики, повторы, интерфейс |
| `dudraugai.css` | палитра из ТЗ, Manrope / Noto Sans, мобильные сетки, тёмная тема сайта |
| `dudraugai-test.js` | `node dudraugai-test.js` — контрольные формы, целостность базы, сборка заданий в браузере (если установлен Playwright) |

Счётчики на вкладке «Знакомство» вычисляются из данных, вручную нигде
не вписаны.

## Реализовано

- Восемь разделов одной страницы: Знакомство, Предмет и действия, Практика,
  Схемы, База слов, Новые слова, Повторы, Моё пространство. Ссылка на раздел
  работает через `#practice`, `#builder` и т. д.
- Конструктор: предмет → число → карточка имени с jis/ji/jie/jos →
  восемь описаний → действия → действующий aš/tu/jis/ji/mes/jūs/jie/jos →
  итоговая фраза → что изменилось (оба окончания, вопрос ką?). Недоступное
  число не предлагается (durys — только множественное, vanduo — только
  единственное). Смена действующего не меняет число предмета.
- Спряжение в диалоге: настоящее, прошедшее однократное, будущее,
  повелительное; у aš в повелительном тире, третье лицо — tegul + настоящее.
- Четыре формы прилагательного в порядке jis, ji, jie, jos — везде один порядок.
- «Написать самостоятельно» открывает именно то задание, которое собрано
  в конструкторе (предмет + действие + описание + число); задание построено
  с aš, как и все задания «Направить действие».
- Письменная практика, шесть навыков: «Имя и число», «Четыре формы»,
  «Согласование», «Направить действие», «Полный перевод», «Словообразование».
  Фильтры навык / группа прилагательных / предмет, 12 карточек на странице,
  честное пустое состояние.
- Проверка: NFC, нижний регистр с литовской локалью, снятие оговорённой
  пунктуации, схлопывание пробелов; диакритика сохраняется (švarų ≠ svaru).
  Несовпадение целого предложения даёт нейтральное «сравним с примером»,
  а не «ошибка». Эталон и разбор показываются только после попытки.
  Изменение проверенного ответа скрывает прежний результат.
- Литовские буквы ą č ę ė į š ų ū ž вставляются в позицию курсора.
  «Проверить» неактивна при пустом поле. Предел поля — 5000 символов.
- Сохранение в браузере: проверенный ответ (`values`) и черновик (`draft`)
  раздельно, число попыток, время, уровень и дата повтора. Ошибка
  localStorage показывается и не перекрывается сообщением «сохранено».
- Кнопка «Продолжить последнее задание».
- Повторы: интервалы 1, 3, 7, 14, 30 дней; ошибка сбрасывает уровень;
  успех до срока интервал не увеличивает; в режиме повтора поля пустые.
- Моё пространство: поле до 5000 символов, автосохранение, «Сохранить текст»,
  «Скопировать для разбора» (в буфер: текст + инструкция для ChatGPT,
  ничего не отправляется).
- 13 схем-объяснений от первого лица с обязательными уточнениями из ТЗ.
- Словообразование: 36 связок -umas, 13 пар «меняется само / изменяем что-то»,
  10 семейств «материал → описание» (= 72 задания).
- Уведомление об авторском праве и источники внизу страницы.

## Реализовано иначе, чем в ТЗ

- **Вход и облако.** ТЗ описывает вход через платформу ChatGPT, D1 и
  Cloudflare Worker. На статическом сайте сервера нет, поэтому есть только
  гостевой режим: ответы хранятся в браузере устройства. Интерфейс говорит
  об этом прямо и не показывает кнопок входа и синхронизации.
- **Профили сцен вместо ручных 14 сцен.** Все предметы получают описания
  и действия через тематический профиль (`PROFILES` в данных). Это делает
  расширение управляемым, но сочетаемость стоит перечитать редактору:
  профиль может дать одинаковые наборы у соседних предметов.
- **Стек.** Не React / Vite / Tailwind, а обычные HTML, CSS и JS без сборки —
  так работает весь этот сайт и его обновление через веб-интерфейс GitHub.
- **Тёмная тема.** На сайте есть переключатель темы; для тренажёра добавлены
  тёмные варианты палитры ТЗ.

## Чего нет (и что не обещать)

- Входа в аккаунт, облачного прогресса, синхронизации между устройствами,
  конфликтов revision — всё это требует сервера (раздел 22 ТЗ).
- Автоматической ИИ-проверки свободного текста (раздел 31).
- Кабинета преподавателя, озвучивания, ударений, платежей, редактора базы
  через сайт.
- Комнат с изображениями и нажимаемыми предметами (раздел 29) и модуля
  причастий «процесс → результат» (раздел 30).
- Сохранения настроек конструктора и выбранной вкладки между перезагрузками.
- Гарантии вечного хранения в браузере: очистка данных сайта стирает ответы.

## Как расширять без потери прогресса

ID заданий составлены из ID слов: `agreement:langas:švarus:0:acc`,
`action:vonia:plauti:baltas:0`, `forms:gražus:nom`, `translate:12`,
`formation:umas:gražus`. Добавление слов, описаний и действий не меняет
старые ID. Переименование или удаление слова, перестановка описаний внутри
профиля (описание для задания «Направить действие» входит в ID, поэтому
перестановка действий содержание не меняет) обнуляют связанные ответы.
Переводы нумеруются по порядку — вставлять новые только в конец списка.

После правок: `node dudraugai-test.js`.
