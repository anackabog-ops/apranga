## Структура

Все файлы лежат в одной папке, **без вложенных каталогов**. Так сделано
намеренно: при загрузке через веб-интерфейс GitHub вложенные папки
схлопываются, и сайт ломается. Плоская структура это исключает.

```
index.html            главная
kursas.html           курс и методика
veiksmazodziai.html   семь глагольных корней
zodynas.html          словарь (поиск по таблицам)
praktika.html         примерка, магазин, уход, сезоны
niuansai.html         идиомы и ошибки русскоязычных
treniruokle.html      тренажёр по глаголам
linksniai.html        Vardininkas и Galininkas: теория + тренажёр
jos.html              местоимение jos
apie.html             об авторе
teises.html           авторские права и условия использования
404.html              страница ошибки
style.css             всё оформление: палитра, темы, печать
linksniai.css         своя палитра и компоненты страницы падежей
app.js                навигация, поиск, тренажёры, переключатель темы
linksniai.js          базы слов и движок тренажёра по падежам
01…16-*.webp          16 иллюстраций
netlify.toml  robots.txt  sitemap.xml
```

Ссылки между страницами относительные, поэтому сайт открывается и просто
двойным щелчком по `index.html` — сервер для просмотра не нужен.

Страница `linksniai.html` — единственная со своим оформлением: она подключает
`style.css`, а следом `linksniai.css`, который переопределяет палитру
(Peapod · Bechamel · Going green · Lava Falls) и шрифты (Manrope + Noto Sans).
Остальных страниц это не касается — `style.css` не тронут.

## Как обновить сайт

1. Соберите новую версию (или получите готовую папку).
2. На github.com в репозитории: **Add file → Upload files**.
3. Перетащите **все файлы** новой версии. Одноимённые заменятся.
4. **Commit changes**.

Netlify пересоберёт сайт автоматически за полминуты и сохранит предыдущую
версию — на неё можно откатиться в один клик.

## Авторские права

Права на материалы возникли в момент их создания и регистрации
не требуют. В репозитории они обозначены в четырёх местах — если
будете добавлять файлы, повторите то же самое:

1. **`LICENSE`** — полные условия, русский и английский текст.
2. **`teises.html`** — те же условия человеческим языком, страница
   сайта. На неё ведут `<link rel="license">` в `<head>` каждой
   страницы и ссылка «Права и условия» в подвале.
3. **Знак © внутри файлов.** В начале `style.css`, `app.js`,
   `linksniai.css`, `linksniai.js` стоит комментарий `/*! … */` —
   такие комментарии переживают минификацию, поэтому авторство
   не теряется, даже если файл кто-то пересоберёт.
4. **Машиночитаемая разметка.** В `<head>` каждой страницы —
   блок `application/ld+json` со схемой `schema.org`: `author`,
   `copyrightHolder`, `copyrightYear`, `copyrightNotice`,
   `creditText`, `license`. Это то, что читают поисковики
   и агрегаторы; оттуда же берётся подпись при переиспользовании.

Плюс `<meta name="author">` и `<meta name="copyright">` — они были
на страницах и раньше.

Даты создания подтверждаются сами: история коммитов в GitHub и
история деплоев в Netlify пишутся с отметками времени и учётной
записью автора. Для договоров и споров этого может не хватить —
там нужен нотариус или депозитарий произведений и разговор
с юристом; в файлах сайта сделано всё, что в них можно сделать.

## Свой домен

Netlify → **Domain management → Add a domain**, затем CNAME в DNS домена.
Сертификат выпускается автоматически. После смены адреса нужно обновить
его в `sitemap.xml`, `robots.txt` и в тегах `canonical` / `og:url`
на каждой странице.
