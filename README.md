# Du draugai · Vardininkas и Galininkas

Тренажёр двух литовских падежей по методике Божены Анацкой.
Живёт по адресу <https://du-draugai.netlify.app>

**Автор методики и учебных материалов — Божена Анацкая
([anacka.lt](https://www.instagram.com/anacka.lt/)).**
© 2026. Все права защищены — см. [LICENSE](LICENSE).

Назвать. Представить. Взаимодействовать: ученик выбирает предмет, узнаёт
его имя, род и число, создаёт образ описаниями, направляет на предмет
действие и пишет собственное предложение — с проверкой и разбором.

## Структура

Все файлы лежат в одной папке, **без вложенных каталогов**: при загрузке
через веб-интерфейс GitHub вложенные папки схлопываются, и сайт ломается.

```
index.html    сайт целиком: восемь разделов тренажёра
styles.css    палитра, шрифты, сетки, светлая и тёмная тема
data.js       база: существительные, прилагательные, глаголы, сцены
app.js        задания, проверка, сохранение, повторы, интерфейс
test.js       проверка базы: node test.js
404.html  favicon.svg  netlify.toml  robots.txt  sitemap.xml
```

Ссылок на другие страницы нет — сайт открывается и двойным щелчком по
`index.html`, сервер для просмотра не нужен.

## Разделы

| Раздел | Что делает |
|--------|------------|
| Знакомство | два друга, цепочка одного предмета, правило вопросов, счётчики базы |
| Предмет и действия | сборка фразы: предмет, число, описание, действие, действующий |
| Практика | письменные задания шести навыков с проверкой и разбором |
| Схемы | тринадцать подробных объяснений |
| База слов | существительные, прилагательные, глаголы со спряжением |
| Новые слова | словообразование: -umas, gerėti / gerinti, материал → описание |
| Повторы | интервальная практика по результатам ученика |
| Моё пространство | свободный текст с автосохранением |

Что реализовано, что сделано иначе и чего пока нет — в [STATUS.md](STATUS.md).

## Как обновить сайт

1. На github.com в этом репозитории: **Add file → Upload files**.
2. Перетащите изменённые файлы. Одноимённые заменятся.
3. **Commit changes**.

Netlify пересоберёт сайт автоматически за полминуты и сохранит предыдущую
версию — на неё можно откатиться в один клик.

## Правка содержимого

Слова и задания лежат в `data.js`, тексты объяснений — прямо в
`index.html`. Подробно: [CONTENT.md](CONTENT.md).
После любой правки базы запустите `node test.js`.

## Свой домен

Netlify → **Domain management → Add a domain**, затем CNAME в DNS домена.
Сертификат выпускается автоматически. После смены адреса обновите его в
`sitemap.xml`, `robots.txt` и в тегах `canonical` / `og:url` в `index.html`.
