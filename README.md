## Посмотреть локально

Страницы ссылаются друг на друга от корня сайта, поэтому открывать
`index.html` двойным щелчком нельзя — нужен локальный сервер:

```bash
cd apranga-site
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>. Остановить — Ctrl+C.

## Опубликовать на Netlify

### Через GitHub — обновляется само

1. Создайте на GitHub пустой репозиторий, например `apranga`.
2. В этой папке:

```bash
git remote add origin git@github.com:ВАШ_ЛОГИН/apranga.git
git push -u origin main
```

3. Netlify → **Add new site → Import an existing project → GitHub** → выберите репозиторий → **Deploy**.
   Build command оставьте пустым, publish directory — `.` (это уже задано в `netlify.toml`).

### Без терминала

Загрузите файлы через веб-интерфейс GitHub («uploading an existing file»)
или перетащите папку на <https://app.netlify.com/drop>.

## После публикации

Замените `ВАШ-ДОМЕН` на настоящий адрес в `sitemap.xml`, `robots.txt`
и в теге `<link rel="canonical">` на каждой странице.

## Структура

```
index.html            главная
<раздел>/index.html   страницы разделов
assets/style.css      всё оформление: палитра, темы, печать
assets/app.js         навигация, поиск, тренажёры, переключатель темы
assets/img/           16 иллюстраций (webp, ~2 МБ суммарно)
404.html  sitemap.xml  robots.txt  netlify.toml
```

Как править содержимое и добавлять новые темы — в [CONTENT.md](CONTENT.md).
