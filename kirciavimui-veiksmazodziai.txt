# Ударение 1-го и 2-го лица единственного числа выводится из ТРЕТЬЕГО лица:
#
#   • третье лицо с акутом (á, tvirtapradė) — ударение неподвижно,
#     во всех лицах остаётся на том же слоге:   sė́di → sė́džiu, sė́di
#   • третье лицо с тильдой (ã, tvirtagalė) или с кратким ударным
#     гласным (à) — ударение подвижное, в 1-м и 2-м лице единственного
#     уходит на окончание:                      vel̃ka → velkù, velkì
#
#   Множественное число ударяется так же, как третье лицо.
#
# Поэтому размечать нужно не 9240 форм, а 560: по два третьих лица
# на каждый из 280 глаголов. Остальное страница выведет сама.
#
# ЧТО ДЕЛАТЬ

#   2. Вставляйте по одной части (они помечены «--- часть N ---»).
#   3. Верните размеченный текст — порядок слов можно не сохранять,
#      каждая форма опознаётся по написанию без знаков.
#

#
